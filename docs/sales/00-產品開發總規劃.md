# POS Pro 印尼版 — 完整開發與開賣總規劃

> 目標客群：**Warung**（雜貨店/小吃攤）與 **Rumah Makan**（家常餐館）
> 原則：用現有功能能賣就賣，只補「不做就賣不掉」的功能，其他上市後再說。

---

## 現況盤點：已經有的 vs 缺的

### ✅ 已具備（不用開發）
| 功能 | 對應客群需求 |
|------|-------------|
| 離線收銀、掃條碼、混合付款、找零 | Warung 核心 |
| 庫存管理、安全庫存提醒、過期警示 | Warung（雜貨有效期） |
| 顧客掃碼點餐（已有桌號概念） | Rumah Makan 核心 |
| 會員點數/儲值 | 兩者（印尼小店常有賒帳熟客文化） |
| 報表、交班、盤點、廢棄記錄 | 兩者 |
| PWA 手機/平板安裝 | 銷售通路基礎 |
| 雲端同步（Supabase，選用） | 線上版加購 |

### ❌ 缺的（開賣前必補，按優先序）

| # | 功能 | 為什麼不做賣不掉 | 工作量 |
|---|------|------------------|--------|
| 1 | **印尼文/英文 i18n + Rp 貨幣** | 客人看不懂中文 | 5–7 天（最大項） |
| 2 | **QRIS 付款方式** | QRIS 是印尼國家統一掃碼支付，小店標配。做法極簡：老闆上傳自己的 QRIS 圖，結帳選 QRIS 時全螢幕顯示給客人掃，人工確認到帳。**不做金流串接** | 1 天 |
| 3 | **啟用碼系統** | 防轉賣、控銷售 | 1–2 天 |
| 4 | **藍牙熱感出單機（58mm）** | 印尼小店最普及的印單機（Rp 200–300 千的便宜機型，ESC/POS 協議）。Rumah Makan 沒有廚房單就不能用。Android Chrome 支援 Web Bluetooth，可直接印 | 3–4 天 |
| 5 | **WhatsApp 收據** | 印尼人什麼都用 WA。做法極簡：結帳後產生 `wa.me/?text=收據文字` 連結，一鍵傳給客人。零串接、零成本 | 半天 |

### ⏸ 上市後再做（先跳過）
- 廚房顯示螢幕 KDS（先用出單機印廚房單就夠）
- GoFood / GrabFood 外送平台串接（等有客人要求）
- 正式金流 API（QRIS 靜態圖夠用，串 API 要在印尼設公司）
- iOS 藍牙列印（iPhone 不支援 Web Bluetooth；先主打 Android，印尼 Android 市占 ~90%）

## 開發時程（總計約 3 週）

### 第 1 週：i18n 三語化
- 抽出全部 UI 字串（14 頁 + 元件）成字典檔 `zh / en / id`
- 語言切換（首次啟用選、設定頁可改）
- Rp 格式：`Rp 15.000`（千分位用點、無小數）；日期 DD/MM/YYYY
- 掃碼點餐頁（public/menu）同步三語化 — 這是客人看的，最重要
- 印尼文翻譯品質：先機翻＋你校對，上市前找一位印尼母語者過一遍 UI（Fiverr 約 USD 30–50）

### 第 2 週：付款與硬體
- QRIS：設定頁上傳 QRIS 圖 → 結帳新增「QRIS」付款方式 → 全螢幕顯示 QR
- WhatsApp 收據：結帳完成頁加「Kirim via WA」按鈕
- 藍牙熱感列印（Web Bluetooth + ESC/POS）：
  - 收銀收據（LOGO、品項、QRIS 說明、Terima kasih）
  - 廚房單（桌號、品項、備註，字體加大）
  - 買 1–2 台印尼熱賣機型實測（如 EPPOS、Panda PRJ-58D，蝦皮就有）

### 第 3 週:啟用碼 + 部署 + 打磨
- Supabase licenses 表 + 啟用流程（一碼綁 2 台，第 3 台拒絕）
- 預設帳號改英文/印尼文（`Boss/1234` → 提示強制改密）
- 部署 Cloudflare Pages + 短網域
- 低階手機實測（印尼主流是 RAM 3–4GB 的 Android，找台便宜的 Redmi/Infinix 測）
- 走一遍 TESTING_CHECKLIST + 三語切換全頁檢查

## 兩種店型的銷售包裝

同一套軟體,賣的時候包裝成兩個「方案」（只是話術和示範重點不同）：

### 📦 Paket Warung（雜貨店包）
- 示範重點：掃條碼快速結帳、庫存警示、過期提醒、進貨管理
- 硬體搭配：手機即可（條碼用鏡頭掃），加購出單機選配
- 話術：「不用再用本子記帳，每天賺多少一眼看到」

### 🍜 Paket Rumah Makan（餐館包）
- 示範重點：**桌上貼 QR 客人自己點餐** → 廚房自動出單 → QRIS 收款 → WA 收據
- 硬體搭配：平板（收銀台）＋ 藍牙出單機（廚房）＝ 總成本約 Rp 1.5–2 juta
- 話術：「客人掃碼自己點，不用請點餐員」— 這是省人力，最有感

### 定價（參考）
| 方案 | 價格 |
|------|------|
| 軟體買斷（2 台裝置） | Rp 399.000–499.000 |
| 雲端同步加購 | Rp 50.000/月 或 Rp 400.000/年 |
| 硬體套組（代購平板+出單機，賺價差） | 市價 + 15–20% |
| 到府安裝教學 | Rp 100.000–150.000 |

**硬體套組是隱藏利潤點**：幫客人配好「平板＋出單機＋支架」開箱即用，客人省麻煩、你賺價差，業務也更好成交（賣的是「整套解決方案」不是「一個 App」）。

## 開賣通路執行（沿用前份計劃，重點補充）

1. **Shopee**：兩個商品頁分開上 — 「Aplikasi Kasir Warung」和「Aplikasi Kasir Rumah Makan」，關鍵字不同（kasir warung / kasir restoran / aplikasi kasir offline tanpa bulanan），內容其實同一套軟體
2. **Instagram/TikTok**：印尼 TikTok 滲透率極高，同支影片雙發。Rumah Makan 的「掃碼點餐」演示影片最有傳播力（拍：客人掃桌上 QR → 點餐 → 廚房機器吐單）
3. **業務地推**：餐館聚集區掃街，用 Paket Rumah Makan 話術現場演示
4. **WhatsApp Business**：售後 + 成交都在 WA，設好目錄（Catalog）功能可直接展示方案價格

## 風險與對策

| 風險 | 對策 |
|------|------|
| 印尼文翻譯不道地被嫌 | 上市前母語者校對 UI + 教學文件 |
| 便宜出單機協議不相容 | 只承諾支援清單上的機型（實測過的 2–3 款），其他「不保證」 |
| iPhone 用戶要藍牙列印 | 明講：列印功能限 Android/平板；iPhone 可當第二台看報表 |
| 客人不會操作、退貨 | 到府安裝方案 + 60 秒教學影片 + WA 客服；Shopee 商品頁寫清楚「數位商品啟用後不退」 |
| Supabase 免費額度爆 | 啟用驗證流量極小不會爆；雲端同步客戶多了再升級付費層（那時已有收入） |
