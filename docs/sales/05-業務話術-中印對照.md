# 業務 5 分鐘成交話術（中文／印尼文對照）

## 開場（30 秒）
- 中：老闆，現在店裡怎麼記帳？用本子還是 Excel？
- ID: *Pak/Bu, sekarang catat penjualan pakai apa? Buku tulis atau Excel?*

## 演示（2 分鐘）— 用自己的示範機
1. 掃條碼 → 結帳 → 找零（示範一單 30 秒完成）
   - ID: *Scan barcode → bayar → kembalian. Satu transaksi cuma 30 detik.*
2. 打開今日報表：今天賣多少、賺多少，一眼看到
   - ID: *Laporan hari ini: omzet dan untung langsung kelihatan.*
3. 庫存快沒了會自動提醒
   - ID: *Stok mau habis? Aplikasi kasih peringatan otomatis.*

## 殺手句（30 秒）
- 中：一次付費，**沒有月費**。沒有網路也能用。
- ID: *Bayar sekali, **TANPA biaya bulanan**. Tidak ada internet juga tetap jalan.*
- 中：別家 POS 每月收 Rp 200–400 千，我們一次付清比他們兩個月月費還便宜。
- ID: *POS lain bayar Rp 200–400 ribu tiap bulan. Punya kami bayar sekali, lebih murah dari 2 bulan langganan mereka.*

## 異議處理
| 客人說 | 回答（ID） |
|--------|-----------|
| 太貴了 | *Hitung saja: buku tulis gratis tapi salah hitung tiap hari. Ini modal sekali, dipakai bertahun-tahun.* |
| 我不會用手機 | *Saya install dan ajarkan sekarang, 5 menit langsung bisa.*（我現在裝給你，5 分鐘就會用） |
| 怕資料不見 | *Data ada di HP Bapak/Ibu sendiri, bisa ekspor backup kapan saja.* |
| 要問老婆/老公 | *Boleh, saya kirim video demo ke WhatsApp. Besok saya mampir lagi.*（留 WhatsApp，隔天回訪） |

## 成交（2 分鐘）
1. 當場收款（現金 / QRIS / 轉帳）
2. 當場照三步驟安裝（開網址 → 加入主畫面 → 輸入啟用碼）
3. 教基本操作：新增商品、結帳一單、看報表
4. 留 WhatsApp 客服卡片
- ID: *Sudah selesai! Ada masalah apa saja, WhatsApp nomor ini.*
