# POS Pro 印尼銷售完整計劃

> 產品：POS Pro 離線收銀系統（PWA，手機/平板免上架直接安裝）
> 市場：印尼小型零售（雜貨店 warung、小吃攤、服飾攤）
> 通路：Instagram + Shopee（蝦皮印尼站）

---

## 第一階段：產品準備（開賣前必須完成）

| # | 工作 | 說明 | 預估 |
|---|------|------|------|
| 1 | 三語化（中/英/印尼） | UI 字串抽成字典檔，設定頁加語言切換 | 3–5 天 |
| 2 | 貨幣格式 Rp | 印尼盾無小數位，千分位用「.」（Rp 15.000） | 併入 #1 |
| 3 | 啟用碼系統 | Supabase 免費版一張 licenses 表；首次開啟需連網輸碼綁定裝置，之後全離線 | 1–2 天 |
| 4 | 部署 | Cloudflare Pages（免費），買一個好記的短網域（例：pospro.id 或 .com，年費約 USD 10） | 半天 |
| 5 | 教學文件 | 三語安裝教學（本包已附）＋ 一支 60 秒安裝示範影片（手機錄屏即可） | 1 天 |

**網域很重要**：客人要手打網址，越短越好。開賣前定案，教學文件裡的 `【你的網址】` 全部替換。

## 第三階段：Shopee 上架

Shopee 印尼可賣數位商品，流程：

1. 商品上架為「數位商品／軟體」類別，商品圖用 App 截圖＋「TANPA BIAYA BULANAN」（免月租）大字
2. 客人下單付款後，**透過 Shopee 聊天發送**：
   - 啟用碼（1 組）
   - 安裝網址
   - 三語教學 PDF（或圖片版，共 4 張圖）
3. 客人確認收貨 → 訂單完成

**注意**：Shopee 規定數位商品要在商品說明寫清楚交付方式（聊天發碼），先寫明避免糾紛。啟用碼發出前先在你的後台標記訂單編號，退款時可作廢該碼。

### Shopee 商品說明模板（印尼文重點句）
- Aplikasi kasir OFFLINE — tidak perlu internet setelah aktivasi（離線收銀，啟用後不需網路）
- Sekali bayar, TANPA biaya bulanan（一次付費，免月租）
- Install langsung di HP/tablet Android & iPhone — tidak perlu Play Store（手機直接安裝，不用商店）
- Kasir + Stok + Member + Laporan（收銀＋庫存＋會員＋報表）

## 第四階段：Instagram 銷售

1. **帳號定位**：功能短影片為主 — 每支 15–30 秒示範一個功能（掃條碼結帳、看日報表、庫存警示），印尼文字幕
2. **內容排程**：每週 3 支 Reels + 限動互動（投票：「你的店還在用紙本記帳嗎？」）
3. **成交流程**：DM 詢問 → 傳示範影片 → 收款（**印尼主流：轉帳 BCA / DANA / OVO / GoPay / QRIS**）→ 傳啟用碼＋教學
4. **Bio 連結**：放 linktr.ee → 安裝教學頁 + WhatsApp 客服連結（印尼人習慣用 WhatsApp 談生意，準備一個 WhatsApp Business 號碼）

## 第五階段：業務/經銷模式

讓在地業務幫你賣（他們有店家人脈）：

1. 業務用**示範機**（自己手機裝好的版本）到店演示 5 分鐘
2. 成交後業務當場幫店家安裝（照教學 3 步驟，5 分鐘完成）
3. 你發碼給業務 → 業務啟用 → 抽成（建議 20–30%）
4. 給業務的工具包：教學 PDF、示範話術（見下）、批發碼價格表

### 業務 5 分鐘話術（印尼文教學文件內附完整版）
1. 問：「現在怎麼記帳？」（多半是紙本或 Excel）
2. 演示：掃條碼 → 結帳 → 看今日營收（30 秒完成一單）
3. 殺手句：「一次付費，沒有月費，沒網路也能用」
4. 當場裝給他看：「5 分鐘就能開始用」

## 客服與售後

- **WhatsApp Business** 一個號碼處理售後（設定自動回覆常見問題）
- 常見問題預先做成圖卡：換手機怎麼辦（重新綁定，後台把舊裝置解綁）、資料備份（App 內建 CSV 匯出）
- 每組啟用碼在後台記錄：訂單編號、客人 WhatsApp、啟用日期 — 出問題可查

---

## 防轉賣機制摘要

- 啟用碼一碼綁 2 台裝置，第 3 台拒絕啟用
- 客人轉賣 = 要把自己裝置解綁，自己就不能用了
- 後台可查每組碼的啟用狀況，異常（頻繁換綁）可停用該碼
