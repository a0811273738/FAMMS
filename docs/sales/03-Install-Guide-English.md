## FAQ

**Q: Does it work without internet?**
A: Yes. Internet is only needed once, for activation. After that it runs fully offline.

**Q: How many devices can I install on?**
A: One activation code works on **2 devices** (e.g., store tablet + owner's phone).

**Q: What if I change my phone?**
A: Contact support to unbind your old device, then activate on the new one.

**Q: Is my data safe?**
A: Data is stored on your own device. Back it up regularly via "Settings → Export" (CSV). The optional cloud plan syncs automatically.
